# Security Policy

## Supported versions

Only the latest published version is supported with security updates.

## Reporting a vulnerability

Use GitHub's private security advisory feature for this repository. Do not open a public issue for vulnerabilities and do not include credentials, tokens, account identifiers, session identifiers, private prompts, or unredacted request headers.

Reports should include affected versions, impact, reproduction steps using synthetic data, and any proposed remediation. Maintainers will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.
